╔══════════════════════════════════════════════════════════════════════════════╗
║                        GETTING STARTED (QUICK START)                         ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. CHOOSE YOUR STACK
   ✓ Just API? Use: basic-api
   ✓ Web app? Use: web-app
   ✓ Microservices? Use: multi-service-api

2. GENERATE THE STACK
   cd stacks/basic-api
   terragrunt stack generate

3. INITIALIZE
   terragrunt stack run -- init
   ⏱ Wait ~2 minutes for provider setup

4. PLAN
   terragrunt stack run -- plan
   📋 Review all resources to be created

5. DEPLOY
   terragrunt stack run -- apply
   ⏱ Wait ~5 minutes for infrastructure

6. VERIFY
   terragrunt stack output
   curl https://$(output cloudfront_domain_name)/api/health

7. CLEANUP (optional)
   terragrunt stack run -- destroy

PARALLEL EXECUTION
   Terragrunt automatically deploys independent units in parallel
   Example: network and notification run simultaneously

DEPENDENCY ORDERING
   Each stack respects module dependencies:
     network → cluster, database
     cluster + database → ecs services
     services → alarms

PARTIAL DEPLOYMENT
   Deploy just one unit:
     cd stacks/basic-api
     terragrunt stack generate
     terragrunt -chdir=.stack/network apply

CUSTOM STACKS
   Create your own by combining units:
     mkdir stacks/my-stack
     Create terragrunt.stack.hcl with your units
     Deploy like any other stack

Ready to deploy?

1. Start with Basic API:
   cd stacks/basic-api && terragrunt stack run -- apply

2. Test your API:
   curl https://your-cloudfront-domain.cloudfront.net/api/health

3. Scale to Web App:
   cd stacks/web-app && terragrunt stack run -- apply
   Upload your frontend: aws s3 sync ./frontend/dist s3://bucket/

4. Add Microservices:
   cd stacks/multi-service-api && terragrunt stack run -- apply
   Deploy worker services alongside your main API

5. Customize:
   Modify terragrunt/dev/* to suit your needs
   Create additional stacks as needed


Questions? See STACKS_GUIDE.md for detailed examples!
